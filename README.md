# TODOリスト

ビルド不要のシンプルなTODOアプリです（HTML / CSS / JavaScript のみ）。

## 使い方

`index.html` をブラウザで開くだけで動きます。

## 機能

- TODOの追加（入力して Enter または「追加」）
- 完了 / 未完了の切り替え（チェックボックス）
- 編集（テキストをダブルクリック → Enter で確定、Esc で取消、空にすると削除）
- 削除（行にマウスを乗せると表示される ×）
- 表示の切り替え（すべて / 未完了 / 完了済み）
- 完了済みの一括削除
- データはブラウザの localStorage に保存され、再読み込みしても残ります

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | 見た目（ダークモード対応） |
| `app.js` | 動作とデータの保存 |
